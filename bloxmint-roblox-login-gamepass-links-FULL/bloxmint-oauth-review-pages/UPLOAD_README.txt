OTHER ROBLOX REVIEW FIELDS:
Description:
BloxMint Gamepass is a fan-made website where users can link a Roblox account through Roblox OAuth, browse Roblox gamepasses, and verify owned passes. Verified ownership can be announced in our Discord server. Purchases take place directly on Roblox.

Category: Account Linking Tools
Justification:
BloxMint links Roblox accounts to our external gamepass store so that we can associate gamepass ownership checks with the correct Roblox user. We use openid to authenticate the Roblox identity and profile to display basic account information after sign-in. We do not request access to unrelated user resources.

Demo video: 60 seconds or less, accessible URL. Start signed out; click Link with Roblox; show Roblox permission/consent page; authorize; show return to BloxMint and linked account. Make sure no secrets are visible.
